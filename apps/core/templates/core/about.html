This project was built by a group of CDAC Big Data Engineering students to demonstrate how raw data can be ingested, transformed, and served through a modern pipeline — and made accessible through both a live dashboard and a conversational, RAG-powered chatbot. This site launches ahead of the pipeline's real data becoming available, using placeholder data everywhere so the same structure can later be pointed at live results without a redesign.
